# CD Ripper & Player
Get the latest version: [v1.0.0](https://github.com/kristheredpanda/cd-ripper-and-player/releases/tag/v1.0.0)

This program can rip tracks from your CD and save it to a folder in the program's directory on your computer so the program can play the songs.
